# M2-C: Preview Studies Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show study tiles (Blurred, Values, Blur + Values) in the live preview without janking the main thread or breaking the phone memory budget. A bounded, single-job provider renders each study tile in a worker from the in-memory preview bitmap, with the same `renderTile` + study code the PDF export uses, and `PagePreview` draws the results as they arrive. It never draws the original pixels where a study tile belongs.

**Architecture:** Three pieces.

1. **C1, the provider** (`src/features/studies/preview/provider.ts`): pure TypeScript implementing the render-owned `StudyTileProvider` interface. Consumers (one per mounted `PagePreview`) declare what they **want**. The provider keeps a FIFO queue, runs **one** job at a time through an injected `render(plan, bitmap, study)`, keeps wanted results, retains up to 32 MB of no-longer-wanted results in LRU order, and remembers the newest image per **slot** so a re-keyed tile can show its previous image while the new one renders (M2-R12). Each job crops the integer box out of the preview bitmap (`cropBitmap`), exactly as export does, and hands the clone to the renderer, which owns and closes it. Notifications are batched per animation frame through an injected `schedule`.
2. **C2, the worker and client** (`study.worker.ts`, `worker-api.ts`, `study-client.ts`): the worker exposes `init()` and `renderStudyTile(plan, bitmap, study)` = `renderTile(bitmap, plan, OffscreenCanvas factory, study)` → `transferToImageBitmap()`. The client creates the worker lazily on the first job and falls back to the same function on the main thread (DOM canvases) when `init()` rejects (M2-R11). `createAppStudyProvider(getSource)` returns the app singleton; the app passes the preview-bitmap getter (ruling D-CR1), so `studies/preview` never imports the images store.
3. **C3, PagePreview** (`render/components/PagePreview.tsx`, `render/preview/*`): an optional `studyTiles` prop. Original tiles keep the M1 synchronous path and cache. Study tiles go through the provider. The component also adds `aria-busy`, version chips, group outlines (guides on), "`<name>`, `<Version>`" tile names, and warning chips on the first tile of a group only (M2-R13/R14).

**Tech Stack:** TypeScript 6 (strict, `noUncheckedIndexedAccess`), React 19, Vitest 5 (`unit` node project for C1/C2 logic, `dom` happy-dom project for C3), fast-check 4, Comlink 4.4, Testing Library.

**Spec:** `docs/spec.md` §2.6 ("All processing runs in a Web Worker. The preview uses a low-resolution version"), §3 (performance, memory), §4 (one page model, two renderers). **Binding:** `docs/superpowers/plans/2026-10-07-m2-overview.md`: Shared contracts → "Preview studies (C1–C3)", "Render (B4, B5)", rulings M2-R5, M2-R11, M2-R12, M2-R13, M2-R14, M2-R16, the memory and performance budgets. The M1 overview's render contracts (CR-E2, CCR-D6, D-1, D-3) still hold.

## Review Focus

Five situations real users hit that the contract does not spell out. Each has a pinned test.

1. **Dragging the blur slider floods jobs.** Every 80 ms the pipeline produces new page models with new keys for the selected image's study tiles. Expected: the queue never grows with stale keys; at most one job is running and the newest wanted key is next; the final picture is the last value. Pinned in C1 (`drops queued keys nobody wants any more: a 30-step drag costs at most 2 renders per tile`) and C3 (`re-wants on every model change and draws the stale slot image meanwhile`).
2. **An image is removed while one of its tiles renders.** Expected: no crash; the result is closed on arrival instead of being stored; no slot keeps a bitmap of a removed image; the queue moves on. Pinned in C1 (`closes a result whose key nobody wants when it arrives`, `closes slot images of an image getSource no longer returns`) and (`skips a queued job whose image is gone`).
3. **Export starts while the preview is processing** (M2-R16). Expected: `pause()` starts no new job, closes every retained bitmap, keeps wanted ones (the preview stays visible under the dialog), lets the in-flight job finish, and `resume()` restarts the queue. Pinned in C1 (`pause: no new job, retained closed, wanted kept; resume restarts`).
4. **More study tiles than the retain cap.** Expected: wanted tiles are never evicted (they are bounded by the sheets' area, see "Memory"); only unwanted tiles count against 32 MB and are closed oldest first. Pinned in C1 (`never evicts a wanted entry even above the cap`, `retains unwanted entries LRU up to the cap and closes the rest`) and the property `wanted bytes never exceed the sheets' area`.
5. **The worker can't start** (no `OffscreenCanvas` 2D in workers, or the worker script fails to load). Expected: the first job falls back to the main-thread renderer, every later job uses it, nothing is lost, and the failure is not a user-facing error. Pinned in C2 (`falls back to the main thread when init rejects`, `falls back when the worker dies mid-job and re-runs that job once`).

## Memory (C's share of the overview budget)

Notation as in the overview: `B(w, h) = w·h·4` bytes; `P` = one preview bitmap ≤ 2048 px long side.

| Class | Bound | Argument | Test |
|---|---|---|---|
| **Wanted** results | ≤ Σ over mounted sheets of `B(deviceW, deviceH)` | A request's plan is made at `previewDpi(scale)` for that sheet, so its `canvasW × canvasH` is the tile's trim+bleed box in sheet device pixels (rounded, never more than +1 px per side and never upscaled past the source). Tiles on a page never overlap (B's invariant, bleed included), so their device areas sum to ≤ the sheet's area plus rounding. M1 already bounds each sheet canvas to `MAX_CANVAS_AREA_PX`. | C1 property `wanted bytes never exceed the sheets' area` (random non-overlapping trims on random sheets, plans from the real `planTilePixels`) |
| **Retained** results | ≤ `STUDY_RETAIN_BYTES` = 32 MB | LRU over entries no consumer wants; insertion closes the oldest until under the cap; `pause()` closes all of them | C1 `retains unwanted entries LRU…` |
| **Slot (stale) images** | ≤ one per slot, and only while that slot is wanted | A slot image is the previous result of a wanted slot; it is the same object as a retained/wanted entry or is closed when the fresh result for the slot arrives or the slot stops being wanted | C1 `replaces the slot image and closes the old one when the fresh tile arrives` |
| **In flight** | one crop clone (≤ `P`) + the renderer's canvases (C2: one tile canvas, one `getImageData` copy, released before resolving) + one result | concurrency 1; the clone is closed by the renderer on every path (C2 test), the result is owned by the provider | C1 `runs one job at a time`; C2 `closes the input bitmap and releases the canvas when the study throws` |

A slot image may also still be a cache entry; ownership is tracked with a reference count per bitmap object (`holders`), and a bitmap is closed exactly when its last holder lets go. C1 has a test that a bitmap is closed **exactly once** in every scenario above (fake bitmaps count `close()` calls and fail on a second call).

- Produces: everything listed under "C1" in "Contract items this plan produces".

**Behaviour, normative** (the code below implements it line for line):

- **Wanted set** = the union of all consumers' requests. `want(consumer, requests)` replaces that consumer's set, then:
  1. every request whose key has no result, is not running, not queued and not failed is appended to the queue, **in the order given** (page order, tile order), deduplicated;
  2. a key that is in the retained LRU and is wanted again leaves the LRU (it is wanted now);
  3. queued keys nobody wants are dropped from the queue;
  4. results nobody wants move to the retained LRU, which then closes the oldest until it holds ≤ `retainBytes`;
  5. slot images whose slot nobody wants, and every entry or slot image whose image `getSource` no longer returns, are released;
  6. failed keys nobody wants are forgotten;
  7. the runner is pumped.
- **Runner:** if not paused and nothing is running, it takes the first queued key that is still wanted and whose image still exists (others are skipped and dropped). It scales the plan to the preview bitmap (`forScaledSource(plan, bitmap.width / pxW, bitmap.height / pxH)`), crops `integerCropBox(scaled.src)` with `cropBitmap`, and calls `render(forCroppedSource(scaled), clone, study)`. `render` owns the clone. When the result arrives:
  - if the key is no longer wanted, the result is **closed** at once;
  - otherwise it is stored, becomes the slot's image (releasing the slot's previous image), and listeners are notified.
  - A rejection whose `name` is `RENDERER_RESTARTED` (C2's "the worker died, the fallback took over") puts the job back at the front of the queue **once** per key; it is cropped again from the preview bitmap, because the first clone was transferred to the dead worker.
  - Any other rejection marks the key failed (`get` keeps returning the slot image or null; `pending` stops counting it). The runner always moves on.
- **`get(key, slot)`** = the result for `key`, else the slot's image, else `null`. It never starts work.
- **`pending(consumer)`** = that consumer's wanted keys with no result and not failed.
- **`subscribe`** listeners are called at most once per `schedule` tick, however many results arrived.
- **`pause()`** stops the runner from starting jobs and releases every retained (unwanted) entry; wanted entries and slot images stay, so the preview under the export dialog stays drawn. The running job finishes normally. **`resume()`** pumps.
- **Ownership:** every bitmap the provider holds has a holder count (cache entry, slot image). It is closed exactly when the count reaches 0. `dispose()` releases everything.

```ts
import type { ImageId } from '../../../../shared/model/image'
import type { TileStudy } from '../../../../shared/model/study'
import { planTilePixels, type PxRect, type TilePixelPlan } from '../../../render/pixels/tile-plan'
import type { StudyTileRequest } from '../../../render/preview/study-tiles'
import { drawTile, id } from '../../../render/test-support/fixtures'
import type { BitmapLike, ProviderDeps, StudyPreviewSource } from '../provider'

/** A bitmap that fails the test if it is closed twice or used after close. */
export class FakeBitmap implements BitmapLike {
  closed = 0
  constructor(
    readonly width: number,
    readonly height: number,
    readonly label = '',
  ) {}
  close(): void {
    if (this.closed > 0) throw new Error(`bitmap closed twice: ${this.label}`)
    this.closed++
  }
}

export interface Deferred<T> {
  promise: Promise<T>
  resolve(value: T): void
  reject(error: unknown): void
}
export function deferred<T>(): Deferred<T> {
  let resolve!: (v: T) => void // assigned synchronously by the Promise executor
  let reject!: (e: unknown) => void // same
  const promise = new Promise<T>((res, rej) => {
    resolve = res
    reject = rej
  })
  return { promise, resolve, reject }
}

export interface RenderCall {
  readonly plan: TilePixelPlan
  readonly clone: FakeBitmap
  readonly study: TileStudy
  readonly result: Deferred<FakeBitmap>
}

export const STUDY: TileStudy = { blurPct: 40, values: null }

/** 1 px per mm (dpi 25.4) so canvasW × canvasH = trim w × h; the fixture image is 3000 × 2000 px. */
export function request(
  imageName: string,
  key: string,
  { w = 100, h = 100, slot = `${imageName}|blurred|0:0`, study = STUDY } = {},
): StudyTileRequest {
  const tile = drawTile({ imageId: id(imageName), trim: { x: 0, y: 0, w, h } })
  return { key, slot, plan: planTilePixels(tile, { dpi: 25.4 }), study, imageId: id(imageName) }
}

/** Deps with controllable renders, a manual schedule and per-image preview sources (1000 × 667 previews of 3000 × 2000 images). */
export function fakeDeps(retainBytes?: number) {
  const renders: RenderCall[] = []
  const crops: { box: PxRect; clone: FakeBitmap }[] = []
  const sources = new Map<ImageId, StudyPreviewSource>()
  const ticks: (() => void)[] = []
  const add = (name: string): void => {
    sources.set(id(name), { bitmap: new FakeBitmap(1000, 667, `preview ${name}`), pxW: 3000, pxH: 2000 })
  }
  const deps: ProviderDeps<FakeBitmap> = {
    getSource: (imageId) => sources.get(imageId),
    cropBitmap: (_bitmap, box) => {
      const clone = new FakeBitmap(box.w, box.h, `clone ${String(crops.length)}`)
      crops.push({ box, clone })
      return Promise.resolve(clone)
    },
    render: (plan, clone, study) => {
      const result = deferred<FakeBitmap>()
      renders.push({ plan, clone, study, result })
      // The real renderer closes its input; the fake does it when the test settles the render.
      return result.promise.finally(() => {
        clone.close()
      })
    },
    schedule: (cb) => {
      ticks.push(cb)
    },
    ...(retainBytes === undefined ? {} : { retainBytes }),
  }
  /** Run every scheduled notification. */
  const flush = (): void => {
    for (const cb of ticks.splice(0)) cb()
  }
  /** Let the provider's promise chains run. */
  const settle = async (): Promise<void> => {
    for (let i = 0; i < 5; i++) await Promise.resolve()
  }
  /** Resolve render n with a bitmap of the plan's canvas size, then let the provider react. */
  const finish = async (n: number): Promise<FakeBitmap> => {
    const call = renders[n]
    if (!call) throw new Error(`no render ${String(n)}`)
    const out = new FakeBitmap(call.plan.canvasW, call.plan.canvasH, `result ${String(n)}`)
    call.result.resolve(out)
    await settle()
    return out
  }
  return { deps, renders, crops, sources, add, flush, settle, finish }
}
```

```ts
/** Keys with a byte size, oldest first (Map keeps insertion order). Holds no values: the provider owns them. */
export class ByteLru {
  private readonly sizes = new Map<string, number>()
  private total = 0

  get bytes(): number {
    return this.total
  }

  keys(): IterableIterator<string> {
    return this.sizes.keys()
  }

  has(key: string): boolean {
    return this.sizes.has(key)
  }

  /** Insert or replace; the key becomes the newest. */
  set(key: string, bytes: number): void {
    this.delete(key)
    this.sizes.set(key, bytes)
    this.total += bytes
  }

  touch(key: string): void {
    const bytes = this.sizes.get(key)
    if (bytes !== undefined) this.set(key, bytes)
  }

  delete(key: string): boolean {
    const bytes = this.sizes.get(key)
    if (bytes === undefined) return false
    this.sizes.delete(key)
    this.total -= bytes
    return true
  }

  /** Remove oldest keys until total ≤ cap; returns them, oldest first, for the caller to release. */
  evictOver(cap: number): string[] {
    const out: string[] = []
    for (const [key, bytes] of this.sizes) {
      if (this.total <= cap) break
      this.sizes.delete(key)
      this.total -= bytes
      out.push(key)
    }
    return out
  }

  clear(): string[] {
    const out = [...this.sizes.keys()]
    this.sizes.clear()
    this.total = 0
    return out
  }
}
```

```ts
import type { ImageId } from '../../../shared/model/image'
import type { TileStudy } from '../../../shared/model/study'
import {
  forCroppedSource,
  forScaledSource,
  integerCropBox,
  type PxRect,
  type TilePixelPlan,
} from '../../render/pixels/tile-plan'
import type { StudyTileProvider, StudyTileRequest } from '../../render/preview/study-tiles'
import { ByteLru } from './lru'

/** Preview study tiles render one at a time (memory budget: one in-flight job). */
export const STUDY_PREVIEW_CONCURRENCY = 1
/** Results no consumer wants any more are kept, newest first, up to this many bytes (w × h × 4). */
export const STUDY_RETAIN_BYTES = 32 * 1024 * 1024

export interface BitmapLike {
  readonly width: number
  readonly height: number
  close(): void
}
export interface StudyPreviewSource {
  readonly bitmap: BitmapLike
  readonly pxW: number
  readonly pxH: number
}
export interface ProviderDeps<B extends BitmapLike> {
  getSource(id: ImageId): StudyPreviewSource | undefined
  cropBitmap(bitmap: BitmapLike, box: PxRect): Promise<B>
  render(plan: TilePixelPlan, clone: B, study: TileStudy): Promise<B>
  schedule(callback: () => void): void
  retainBytes?: number
}
export interface StudyPreviewProvider<B extends BitmapLike> extends StudyTileProvider {
  stats(): { wantedBytes: number; retainedBytes: number; queued: number; running: number }
  dispose(): void
}

interface Entry<B> {
  readonly bitmap: B
  readonly imageId: ImageId
  readonly bytes: number
}

const bytesOf = (b: BitmapLike): number => b.width * b.height * 4

/** `error.name` of a render that failed only because its renderer was replaced (C2). Checked by name: errors lose their class across Comlink. */
export const RENDERER_RESTARTED = 'StudyRendererRestarted'
const isRetryable = (e: unknown): boolean =>
  typeof e === 'object' && e !== null && 'name' in e && e.name === RENDERER_RESTARTED

/**
 * The preview's study tile service (overview "Preview studies", rulings M2-R12, M2-R16).
 * Pure: no DOM; bitmaps, cropping, rendering and frame scheduling are injected.
 */
export function createStudyPreviewProvider<B extends BitmapLike>(
  deps: ProviderDeps<B>,
): StudyPreviewProvider<B> {
  const cap = deps.retainBytes ?? STUDY_RETAIN_BYTES
  const wants = new Map<string, readonly StudyTileRequest[]>()
  const entries = new Map<string, Entry<B>>() // wanted + retained results
  const retained = new ByteLru() // the unwanted subset of `entries`
  const slots = new Map<string, Entry<B>>() // newest result per slot
  const holders = new Map<B, number>()
  const failed = new Set<string>()
  const retried = new Set<string>()
  const queue: StudyTileRequest[] = []
  const listeners = new Set<() => void>()
  let running: string | null = null
  let paused = false
  let notifyScheduled = false
  let disposed = false

  const hold = (b: B): void => {
    holders.set(b, (holders.get(b) ?? 0) + 1)
  }
  const letGo = (b: B): void => {
    const n = (holders.get(b) ?? 0) - 1
    if (n > 0) {
      holders.set(b, n)
      return
    }
    holders.delete(b)
    b.close()
  }
  const dropEntry = (key: string): void => {
    const e = entries.get(key)
    if (!e) return
    entries.delete(key)
    retained.delete(key)
    letGo(e.bitmap)
  }
  const dropSlot = (slot: string): void => {
    const e = slots.get(slot)
    if (!e) return
    slots.delete(slot)
    letGo(e.bitmap)
  }

  const wantedKeys = (): Set<string> => {
    const out = new Set<string>()
    for (const reqs of wants.values()) for (const r of reqs) out.add(r.key)
    return out
  }
  const wantedSlots = (): Set<string> => {
    const out = new Set<string>()
    for (const reqs of wants.values()) for (const r of reqs) out.add(r.slot)
    return out
  }
  const imageGone = (id: ImageId): boolean => deps.getSource(id) === undefined

  const notify = (): void => {
    if (notifyScheduled || disposed) return
    notifyScheduled = true
    deps.schedule(() => {
      notifyScheduled = false
      for (const l of [...listeners]) l()
    })
  }

  /** Steps 3–6 of want(): bring queue, cache, slots and failures in line with the wanted set. */
  const reconcile = (): void => {
    const keys = wantedKeys()
    const slotSet = wantedSlots()
    for (let i = queue.length - 1; i >= 0; i--) {
      const q = queue[i]
      if (q && !keys.has(q.key)) queue.splice(i, 1)
    }
    for (const [key, e] of [...entries]) {
      if (imageGone(e.imageId)) dropEntry(key)
      else if (keys.has(key)) retained.delete(key)
      else if (!retained.has(key)) retained.set(key, e.bytes)
    }
    for (const key of retained.evictOver(cap)) {
      retained.set(key, 0) // keep dropEntry's bookkeeping simple: it deletes from `retained` again
      dropEntry(key)
    }
    for (const [slot, e] of [...slots]) {
      if (!slotSet.has(slot) || imageGone(e.imageId)) dropSlot(slot)
    }
    for (const key of [...failed]) if (!keys.has(key)) failed.delete(key)
    for (const key of [...retried]) if (!keys.has(key)) retried.delete(key)
  }

  const pump = (): void => {
    if (paused || disposed || running !== null) return
    const keys = wantedKeys()
    let req: StudyTileRequest | undefined
    while ((req = queue.shift()) !== undefined) {
      if (keys.has(req.key) && !entries.has(req.key) && !imageGone(req.imageId)) break
    }
    if (req === undefined) return
    const job = req
    const source = deps.getSource(job.imageId)
    if (!source) return // unreachable: checked above
    running = job.key
    const scaled = forScaledSource(
      job.plan,
      source.bitmap.width / source.pxW,
      source.bitmap.height / source.pxH,
    )
    void deps
      .cropBitmap(source.bitmap, integerCropBox(scaled.src))
      .then((clone) => deps.render(forCroppedSource(scaled), clone, job.study))
      .then(
        (result) => {
          accept(job, result)
        },
        (error: unknown) => {
          // A restarted renderer (C2: the worker died, the fallback takes over) gets one more try.
          if (isRetryable(error) && !retried.has(job.key)) {
            retried.add(job.key)
            queue.unshift(job)
            return
          }
          failed.add(job.key)
          notify()
        },
      )
      .finally(() => {
        running = null
        pump()
      })
  }

  const accept = (job: StudyTileRequest, result: B): void => {
    if (disposed || !wantedKeys().has(job.key) || imageGone(job.imageId)) {
      result.close()
      return
    }
    const entry: Entry<B> = { bitmap: result, imageId: job.imageId, bytes: bytesOf(result) }
    dropEntry(job.key) // defensive: a key renders at most once while wanted
    entries.set(job.key, entry)
    hold(result)
    for (const reqs of wants.values()) {
      for (const r of reqs) {
        if (r.key !== job.key || slots.get(r.slot)?.bitmap === result) continue
        dropSlot(r.slot)
        slots.set(r.slot, entry)
        hold(result)
      }
    }
    notify()
  }

  return {
    get(key, slot) {
      return entries.get(key)?.bitmap ?? slots.get(slot)?.bitmap ?? null
    },

    want(consumer, requests) {
      if (disposed) return
      wants.set(consumer, requests)
      const queued = new Set(queue.map((q) => q.key))
      for (const r of requests) {
        if (entries.has(r.key) || failed.has(r.key) || r.key === running || queued.has(r.key))
          continue
        if (imageGone(r.imageId)) continue
        queue.push(r)
        queued.add(r.key)
      }
      reconcile()
      pump()
    },

    subscribe(listener) {
      listeners.add(listener)
      return () => {
        listeners.delete(listener)
      }
    },

    pending(consumer) {
      const reqs = wants.get(consumer) ?? []
      return reqs.filter((r) => !entries.has(r.key) && !failed.has(r.key)).length
    },

    release(consumer) {
      if (!wants.delete(consumer)) return
      reconcile()
    },

    pause() {
      paused = true
      for (const key of retained.clear()) {
        retained.set(key, 0)
        dropEntry(key)
      }
    },

    resume() {
      paused = false
      pump()
    },

    stats() {
      const keys = wantedKeys()
      let wantedBytes = 0
      for (const [key, e] of entries) if (keys.has(key)) wantedBytes += e.bytes
      return {
        wantedBytes,
        retainedBytes: retained.bytes,
        queued: queue.length,
        running: running === null ? 0 : 1,
      }
    },

    dispose() {
      disposed = true
      queue.length = 0
      wants.clear()
      listeners.clear()
      for (const key of [...entries.keys()]) dropEntry(key)
      for (const slot of [...slots.keys()]) dropSlot(slot)
      retained.clear()
    },
  }
}
```

Notes for the implementer:

- `retained.set(key, 0)` before `dropEntry` in `reconcile` and `pause` exists only because `evictOver`/`clear` already removed the key from the LRU and `dropEntry` deletes it again; replacing it with a `dropEntry(key, { fromLru: false })` parameter is fine if the reviewer prefers. What matters (and is tested) is that each bitmap is closed exactly once.
- `stats().retainedBytes` must equal the sum of `bytes` over unwanted entries; the tests pin it after release and after eviction.
- The provider never reads `navigator`, `window` or `requestAnimationFrame`: the app passes `schedule: (cb) => requestAnimationFrame(cb)` (C2).

```ts
import type { TileStudy } from '../../../shared/model/study'
import { releaseCanvas, renderTile, type TileCanvas } from '../../render/pixels/render-tile'
import type { TilePixelPlan } from '../../render/pixels/tile-plan'

export interface StudyWorkerApi {
  /** Rejects with "studies:unsupported" when this context cannot render tiles. */
  init(): Promise<void>
  /** Takes ownership of `bitmap` (closed on every path). Resolves with a new bitmap the caller owns. */
  renderStudyTile(plan: TilePixelPlan, bitmap: ImageBitmap, study: TileStudy): Promise<ImageBitmap>
}

export interface StudyWorkerEnv<C extends TileCanvas & CanvasImageSource> {
  readonly supported: () => boolean
  readonly createCanvas: (w: number, h: number) => C
  /** Worker: transferToImageBitmap(). Main thread: createImageBitmap(canvas). */
  readonly toBitmap: (canvas: C) => Promise<ImageBitmap>
}

/**
 * One study tile, exactly as the PDF renders it (same renderTile, same study step before bleed,
 * M2-R5), at whatever resolution the plan says. Testable in node with FakeCanvas.
 */
export function createStudyWorkerApi<C extends TileCanvas & CanvasImageSource>(
  env: StudyWorkerEnv<C>,
): StudyWorkerApi {
  return {
    init: () =>
      Promise.resolve().then(() => {
        if (!env.supported()) throw new Error('studies:unsupported')
      }),

    async renderStudyTile(plan, bitmap, study) {
      let canvas: C | undefined
      try {
        canvas = renderTile(bitmap, plan, env.createCanvas, study)
        return await env.toBitmap(canvas)
      } finally {
        bitmap.close()
        if (canvas) releaseCanvas(canvas)
      }
    },
  }
}
```

```ts
export type StudyRenderFn = (
  plan: TilePixelPlan,
  clone: ImageBitmap,
  study: TileStudy,
) => Promise<ImageBitmap>

export interface StudyEngine extends StudyWorkerApi {
  /** True once a worker engine has failed for good. */
  isDead?(): boolean
}

function restarted(cause: unknown): Error {
  const e = new Error('Study renderer restarted', { cause })
  e.name = RENDERER_RESTARTED
  return e
}

/** Lazy worker with a main-thread fallback (M2-R11). */
export function createStudyRenderer(
  spawn: () => StudyEngine,
  fallback: () => StudyEngine,
): StudyRenderFn {
  let chosen: Promise<StudyEngine> | null = null
  let main: StudyEngine | null = null
  const useMain = (): StudyEngine => (main ??= fallback())
  const choose = (): Promise<StudyEngine> =>
    (chosen ??= (async () => {
      try {
        const worker = spawn()
        await worker.init()
        return worker
      } catch {
        return useMain()
      }
    })())

  return async (plan, clone, study) => {
    const engine = await choose()
    try {
      return await engine.renderStudyTile(plan, clone, study)
    } catch (e) {
      if (engine !== main && engine.isDead?.() === true) {
        chosen = Promise.resolve(useMain())
        throw restarted(e)
      }
      throw e
    }
  }
}

/* v8 ignore start -- browser-only Worker and DOM-canvas wiring; the logic (createStudyWorkerApi,
   createStudyRenderer, createStudyPreviewProvider) is unit-tested and D3/D4 drive this path in E2E. */
function spawnWorkerEngine(): StudyEngine {
  const worker = new Worker(new URL('./study.worker.ts', import.meta.url), { type: 'module' })
  const remote = wrap<StudyWorkerApi>(worker)
  let dead = false
  let fail: (e: unknown) => void = () => undefined
  const failure = new Promise<never>((_, reject) => {
    fail = reject
  })
  failure.catch(() => undefined)
  const die = (message: string) => (): void => {
    dead = true
    worker.terminate()
    fail(new Error(message))
  }
  worker.addEventListener('error', die('Study worker failed'))
  worker.addEventListener('messageerror', die('Study worker sent an unreadable message'))
  return {
    init: () => Promise.race([remote.init(), failure]),
    renderStudyTile: (plan, bitmap, study) =>
      Promise.race([remote.renderStudyTile(plan, transfer(bitmap, [bitmap]), study), failure]),
    isDead: () => dead,
  }
}

function mainThreadEngine(): StudyEngine {
  return createStudyWorkerApi<HTMLCanvasElement>({
    supported: () => true,
    createCanvas: (w, h) => {
      const c = document.createElement('canvas')
      c.width = w
      c.height = h
      return c
    },
    toBitmap: (canvas) => createImageBitmap(canvas),
  })
}
```

  - `study-requests.ts`: `tileSlot(pageIndex, tileIndex, tile): string`, `studyRequestsFor(model: PageModel, dpi: number): StudyTileRequest[]` (study tiles only, in tile order).
  - `TileHitArea` gains `version: StudyVersion`, `groupSize: number`, `firstInGroup: boolean`.
  - `PageDrawColors` gains `group` (from `--color-accent`, fallback `#b0432a`), and `drawPage` draws `page.groups` when guides are on.
  - `PagePreviewProps.studyTiles?: StudyTileProvider`.
  - `preview.json`: `tile.versionName` = `"{{name}}, {{version}}"`.

**Behaviour, normative:**

1. **Two paths.** A tile whose `study` is `null` (`original`) is rendered and cached exactly as in M1 (`syncTileCanvasCache`, keyed by `tileRenderKey`). A study tile never enters that cache: its key slot in the cache is `null`, and the original source pixels are never drawn in its place (M2-R12).
2. **Requests.** On every draw, `studyRequestsFor(model, previewDpi(scale))` builds one request per study tile: `key = tileRenderKey(tile, plan)`, `slot = tileSlot(model.index, i, tile)` = `` `${tile.imageId}|${tile.version}|${pageIndex}:${i}` ``, `plan = planTilePixels(tile, { dpi })` (against the image's `pxW × pxH`; the provider scales it to the preview bitmap), `study = tile.study`, `imageId`. `PagePreview` calls `studyTiles.want(consumer, requests)` with `consumer = useId()`. With no study tiles, it still calls `want(consumer, [])` once, so a page that loses its studies releases them.
3. **Pixels.** `tileImage(i)` for a study tile = `studyTiles?.get(key, slot) ?? null`; `null` draws the "missing" fill (M1 colour).
4. **Redraws.** The component subscribes to the provider; each notification bumps a counter that is a dependency of the draw effect. Draws stay synchronous and cheap (re-wanting the same keys is a no-op in the provider).
5. **Busy.** After each `want` and each notification, `busy = studyTiles.pending(consumer) > 0`; the sheet (`role="group"`) carries `aria-busy={busy || undefined}`. The app-level `PreviewSlot` already sets `aria-busy` for layout work; D2 decides whether the pages list combines them.
6. **Release.** On unmount (and when the provider prop changes) the component calls `release(consumer)` and unsubscribes.
7. **Hit areas.** `tileHitAreas(model)` adds `version`, and finds groups from `model.groups`: the tiles with the outline's `imageId` whose trim lies inside its `block` (± 1e-6 mm) are the group's members, in model order (B4 emits them consecutively, in reading order: ruling CR-M2-5); `groupSize` = member count, `firstInGroup` = the first member. Tiles outside every outline have `groupSize: 1, firstInGroup: true`.
8. **Names (M2-R14).** An `original` tile's accessible name stays the image name (M1 selectors keep working). Other tiles: `t('tile.versionName', { name, version: t('studies:version.<v>') })`, e.g. "pears.heic, Blurred".
9. **Chips (M2-R13/R14).** In a group of ≥ 2 tiles, every tile shows an `aria-hidden` version chip (top-left, the mockup's `tile__study` style) with `studies:version.<v>`. The low-DPI and "Scaled to fit" **visible** chips appear on the first tile of a group only; every tile keeps its screen-reader description (`aria-describedby`), so a screen-reader user hears the warning on whichever tile they reach.
10. **Group outline (guides on).** For each `page.groups` entry, `drawPage` strokes a dashed rectangle 2 mm outside the block (`[6, 4]` dash, 1.5 device px, `colors.group`) after the trim/bleed guides. It is screen-only; the PDF composer ignores `groups`.

```ts
/** Records wants; tests decide what `get` returns and when listeners fire. */
export function fakeStudyTiles() {
  const wants = new Map<string, readonly StudyTileRequest[]>()
  const ready = new Map<string, CanvasImageSource>()
  const stale = new Map<string, CanvasImageSource>()
  const listeners = new Set<() => void>()
  const released: string[] = []
  let paused = false
  const provider: StudyTileProvider = {
    get: (key, slot) => ready.get(key) ?? stale.get(slot) ?? null,
    want: (consumer, requests) => {
      wants.set(consumer, requests)
    },
    subscribe: (l) => {
      listeners.add(l)
      return () => {
        listeners.delete(l)
      }
    },
    pending: (consumer) => (wants.get(consumer) ?? []).filter((r) => !ready.has(r.key)).length,
    release: (consumer) => {
      wants.delete(consumer)
      released.push(consumer)
    },
    pause: () => {
      paused = true
    },
    resume: () => {
      paused = false
    },
  }
  return {
    provider,
    wants,
    released,
    isPaused: () => paused,
    /** All requests currently wanted, flattened. */
    wanted: () => [...wants.values()].flat(),
    /** Mark a key ready with an image and notify listeners. */
    resolve(key: string, image: CanvasImageSource) {
      ready.set(key, image)
      for (const l of [...listeners]) l()
    },
    setStale(slot: string, image: CanvasImageSource) {
      stale.set(slot, image)
    },
```

```ts
import { planTilePixels, tileRenderKey } from '../pixels/tile-plan'
import type { DrawTile, PageModel } from '../types'
import type { StudyTileRequest } from './study-tiles'

/** "The same tile" across re-keys (M2-R12): same image, same version, same place on the same page. */
export function tileSlot(pageIndex: number, tileIndex: number, tile: DrawTile): string {
  return `${tile.imageId}|${tile.version}|${String(pageIndex)}:${String(tileIndex)}`
}

/** One request per study tile of the page, in tile order, planned at the preview's dpi. */
export function studyRequestsFor(model: PageModel, dpi: number): StudyTileRequest[] {
  const out: StudyTileRequest[] = []
  model.tiles.forEach((tile, i) => {
    if (tile.study === null) return
    const plan = planTilePixels(tile, { dpi })
    out.push({
      key: tileRenderKey(tile, plan),
      slot: tileSlot(model.index, i, tile),
      plan,
      study: tile.study,
      imageId: tile.imageId,
    })
  })
  return out
}
```

```ts
const inside = (r: RectMm, box: RectMm): boolean =>
  r.x >= box.x - 1e-6 &&
  r.y >= box.y - 1e-6 &&
  r.x + r.w <= box.x + box.w + 1e-6 &&
  r.y + r.h <= box.y + box.h + 1e-6

/** Group membership per tile index: [size, isFirst]. Tiles outside every outline are groups of one. */
function groupInfo(page: PageModel): { size: number; first: boolean }[] {
  const info = page.tiles.map(() => ({ size: 1, first: true }))
  for (const g of page.groups) {
    const members = page.tiles.flatMap((t, i) =>
      t.imageId === g.imageId && inside(t.trim, g.block) ? [i] : [],
    )
    members.forEach((m, k) => {
      info[m] = { size: members.length, first: k === 0 }
    })
  }
  return info
}

export function tileHitAreas(page: PageModel): TileHitArea[] {
  const { w, h } = page.size
  const groups = groupInfo(page)
  return page.tiles.map((t, i) => ({
    key: `${String(page.index)}:${String(i)}`,
    imageId: t.imageId,
    leftPct: (t.trim.x / w) * 100,
    topPct: (t.trim.y / h) * 100,
    widthPct: (t.trim.w / w) * 100,
    heightPct: (t.trim.h / h) * 100,
    lowDpi: t.lowDpi,
    scaledToFit: t.scaledToFit,
    dpi: tileSourceDpi(t),
    version: t.version,
    groupSize: groups[i]?.size ?? 1,
    firstInGroup: groups[i]?.first ?? true,
  }))
}
```

## Contract change requests

Raised by this plan against the overview's "Preview studies (C1–C3)" block, with the controller's rulings:

- **CCR-C1 (additive, C1↔C2) — accepted:** `RENDERER_RESTARTED` error name. When the worker dies mid-job, the clone it held is gone, so the renderer can't retry by itself; it rejects with this name and the provider re-crops and retries that key **once**. The overview says "a render failure marks the key failed"; this is the one exception.
- **CCR-C2 (additive, C1) — accepted:** `StudyPreviewProvider<B>` adds `stats()` (tests and diagnostics only) and `dispose()` (app teardown/tests) to the `StudyTileProvider` interface the overview lists. The `ProviderDeps.getSource` returns `{ bitmap: BitmapLike; pxW; pxH }` (the overview names `getSource` without its type); this is structurally M1's `PreviewSource` (`{ bitmap, pxW, pxH }`).
- **CCR-C3 (C2) — rejected in favour of D-CR1:** the signature is `createAppStudyProvider(getSource: (id: ImageId) => PreviewSource | undefined)`, a lazily created singleton (the first call's `getSource` wins). `studies/preview` does not import the images store; D2 passes the getter from `src/app/study-provider.ts`.
- **CCR-C4 (C3) — accepted:** `TileHitArea` gains `version`, `groupSize`, `firstInGroup`; `PageDrawColors` gains `group` (from `--color-accent`). Both are render-internal and not in the overview.
- **Ruling CR-M2-5 (B4):** `drawTilesFor` emits a placement's tiles consecutively, in reading order (B4 pins it). C3's `firstInGroup` relies on it.
- **C3 dependency (ruled):** C3 starts after B4 and merges after C1.
- **D-CR3 (ruled, D2):** D2 pauses the provider while the export dialog is open (a superset of M2-R16); C1's `pause`/`resume` need no change.
