# M1 — Collation MVP: Overview & Shared Contracts

> **For agentic workers:** this is the umbrella document for M1. It is **not** executed on its own. M1 is split into five sub-plans (A–E below), each written with superpowers:writing-plans and executed with superpowers:subagent-driven-development. Every sub-plan treats the **Shared contracts** section of this file as binding. A sub-plan that needs a contract change must list it under "Contract change requests" instead of silently diverging.

**Goal:** Ship `v0.1.0`. A user adds reference photos (upload, paste or URL), edits them (crop, rotate, flip, copies, size), chooses page setup (paper, units, orientation, safe area, gutter, crop marks, bleed), and sees a live multi-page preview. The auto layout engine packs the images. The user exports a print-ready PDF. All of it runs in the browser, on desktop and phone.

**Spec:** `docs/spec.md`: §2.1–§2.5 (features), §2.9 (settings), §2.10 (i18n support), §2.11 (basic SEO), §2.12 (look & feel), §3 (non-functional), §4 (architecture), §7 (testing). **Design:** `design/` (approved mockups) and `design/README.md`. **Conventions:** `CLAUDE.md`.

**M1 exit criteria (spec §8):**
- From a phone and from a desktop, you can produce a correctly sized multi-page A4 **and** Letter PDF with crop marks and bleed.
- All tests are green.
- Unit coverage is at least 80% on `src/features/layout/**` and `src/features/render/**` (owner decision P3; studies and lines arrive in M2 and M3).

## Owner decisions that bind M1

- **D1:** on phones, Lines live inside the Studies step. (Irrelevant to M1: there are no studies or lines yet. The M1 phone step flow is **Images → Page → Preview → Export**, and Studies is added in M2.)
- **D2:** crop marks and bleed stay **inside** the safe area.
- **D3:** defaults are crop marks **on**, bleed **off**.
- **D4:** the language picker is **hidden** until M6. Only `en` ships, but every UI string goes through i18n.
- **D5:** fonts are self-hosted: Fraunces (headings), Atkinson Hyperlegible Next (UI), Caveat (hand-written accents, never essential text).
- **D6:** clicking an image on the page preview selects it in the side panels.
- **D10:** the PDF file name is `artistica-<PAPER>-<YYYY-MM-DD>.pdf`, e.g. `artistica-A4-2026-10-03.pdf`. Custom paper uses `Custom`.
- **D11:** keep the placeholder logo for now.
- **R12:** images are memory-only. A `beforeunload` "leave page?" warning appears while images are loaded.
- **Crop interaction (spec §2.2):** drag to move, handles to resize, locked to the chosen aspect, clamped to the image. Works with mouse, touch and keyboard: arrows move, Shift+arrows resize. "Reset crop" restores the full image.

## Shared contracts (binding)

All lengths are millimetres (`Mm`) unless the name says otherwise. Page coordinates have their origin at the **top-left** of the page, x to the right and y downwards. (The PDF composer converts to PDF's bottom-left points.) All model types are plain data: no classes, no `Date`, no `ImageBitmap`. They are serialisable, so they cross worker boundaries.

### `src/shared/model/page-setup.ts` (A)

```ts
export type Orientation = 'auto' | 'portrait' | 'landscape'
export interface PageSetup {
  readonly paper: PaperId
  readonly customSize: SizeMm            // used only when paper === 'Custom' (portrait-normalised: w ≤ h)
  readonly orientation: Orientation
  readonly safeAreaMm: Mm                // ≥ MIN_SAFE_AREA_MM
  readonly gutter: { readonly enabled: boolean; readonly mm: Mm }
  readonly cropMarks: boolean
  readonly bleed: { readonly enabled: boolean; readonly mm: Mm }
}
export const MIN_SAFE_AREA_MM = 3
export const CROP_MARK_LENGTH_MM = 4
export const CROP_MARK_OFFSET_MM = 1      // gap between the bleed edge and the start of a mark
export const DEFAULT_PAGE_SETUP: PageSetup
// { paper: 'A4', customSize: {w:210,h:297}, orientation: 'auto', safeAreaMm: 5,
//   gutter: {enabled: true, mm: 6}, cropMarks: true, bleed: {enabled: false, mm: 3} }

export type PageSetupNote = 'gutter-enabled-for-bleed' | 'gutter-raised-for-bleed' | 'safe-area-raised-to-minimum'
/** Enforce invariants: safeArea ≥ 3; if bleed is enabled, gutter is enabled and gutter.mm ≥ 2 × bleed.mm (raise the gutter, never lower the bleed). Idempotent. */
export function normalizePageSetup(setup: PageSetup): { setup: PageSetup; notes: PageSetupNote[] }
/** Portrait paper size for the setup (customSize for Custom). */
export function paperSizeMm(setup: PageSetup): SizeMm
/** Space reserved outside every trim box for bleed + crop marks (D2: inside the safe area). */
export function outerReserveMm(setup: PageSetup): Mm // (bleed.enabled ? bleed.mm : 0) + (cropMarks ? CROP_MARK_OFFSET_MM + CROP_MARK_LENGTH_MM : 0)
/** Gap between neighbouring trim boxes. */
export function gutterMm(setup: PageSetup): Mm // gutter.enabled ? gutter.mm : 0
/** Area available to trim boxes on an oriented page: page inset by safeAreaMm + outerReserveMm. */
export function contentBoxMm(setup: PageSetup, oriented: SizeMm): { x: Mm; y: Mm; w: Mm; h: Mm }
```

### `src/features/layout/` (B)

```ts
/** One layout unit: a single copy of an image (M2 will set tiles > 1 for study groups). */
export interface LayoutItemInput {
  readonly key: string                 // `${imageId}#${copyIndex}` — unique, stable
  readonly imageId: ImageId
  readonly aspect: number              // printed width / height of ONE tile (after crop & rotation)
  readonly maxPrintWidthMm: Mm         // 300-DPI cap for ONE tile's width
  readonly size: SizeMode              // from edits
  readonly tiles: number               // ≥ 1; tiles of a group are placed side by side (row or column), separated by the gutter
}
export type PlacementWarning = 'low-dpi' | 'scaled-to-fit'
export interface RectMm { readonly x: Mm; readonly y: Mm; readonly w: Mm; readonly h: Mm }
export interface Placement {
  readonly key: string
  readonly imageId: ImageId
  readonly block: RectMm                // trim box of the whole group, page coords
  readonly tiles: readonly RectMm[]     // trim box of each tile, page coords, as printed
  readonly turned: boolean              // true = the engine turned this item 90° clockwise to pack it
  readonly warnings: readonly PlacementWarning[]
}
export interface LayoutResult {
  readonly orientation: 'portrait' | 'landscape'   // resolved (never 'auto')
  readonly pageSize: SizeMm                         // oriented
  readonly pages: readonly { readonly placements: readonly Placement[] }[]
  readonly suggestedPerPage: number                 // "this paper fits N references comfortably per page"
}
export const MIN_COMFORT_SHORT_SIDE_MM = 60
/** Pure, deterministic: the same input gives a deep-equal output. No DOM, no randomness, no Date. */
export function computeLayout(setup: PageSetup, items: readonly LayoutItemInput[]): LayoutResult
/** Expand descriptors into layout items (copies → separate items; computes aspect & 300-DPI cap). */
export function buildLayoutItems(images: readonly ImageDescriptor[]): LayoutItemInput[]
/** Worker-backed async API used by the UI (Comlink). Latest-call-wins: superseded calls reject with an AbortError. */
export function layoutAsync(setup: PageSetup, items: readonly LayoutItemInput[]): Promise<LayoutResult>
```

**Rules:**
- An empty item list gives `pages: []`.
- All tiles are inside `contentBoxMm`. No two blocks overlap.
- The gap between blocks is ≥ `gutterMm(setup)`. In auto mode, no tile exceeds its 300-DPI cap except when it is raised to the comfort minimum, and then it is flagged `low-dpi`.
- A fixed size that doesn't fit is scaled down to fit and flagged `scaled-to-fit`.
- `turned` items have their tile rects in the printed (turned) orientation.
- Performance: 50 items lay out in < 500 ms on a desktop.

### `src/features/images/` (C)

- `useImages`: a Zustand store, **not persisted**.

  ```ts
  { images: LoadedImage[]; selectedId: ImageId | null; importing: number
    addFiles(files: File[]): Promise<ImportOutcome[]>
    addFromClipboard(data: DataTransfer): Promise<ImportOutcome[]>
    addFromUrl(url: string): Promise<ImportOutcome>
    remove(id); clear(); select(id | null)
    updateEdits(id, patch: Partial<ImageEdits>) }
  ```

  - `updateEdits` clamps copies and keeps the crop inside the image and matching the aspect.
- `interface LoadedImage extends ImageDescriptor { readonly name: string; readonly bitmap: ImageBitmap; readonly thumbUrl: string; readonly originalPxW: number; readonly originalPxH: number }`
  - `bitmap` is EXIF-corrected, downscaled to `MAX_SOURCE_LONG_SIDE_PX`, and has transparency flattened onto white.
  - `thumbUrl` is an object URL, revoked on remove/clear.
- `type ImportOutcome = { ok: true; id: ImageId } | { ok: false; source: string; error: ImportErrorCode }`
- `type ImportErrorCode = 'cors' | 'network' | 'not-an-image' | 'unsupported-format' | 'decode-failed' | 'too-large'`. Each code maps to `errors:images.<code>`.
- `selectImageDescriptors(state): ImageDescriptor[]`: a stable, memoised selector that feeds layout and render.
- Components (exported from `src/features/images/index.ts`): `ImportDropzone`, `ImageList`, `ImageEditSheet` (crop editor, rotate/flip, copies, size mode, DPI info). Each is a self-contained block that the shell composes. They read and write `useImages` and read `useSettings().unit`.

### `src/features/render/` (D)

```ts
export interface DrawTile {
  readonly imageId: ImageId
  readonly trim: RectMm                 // page coords
  readonly bleedMm: Mm                  // 0 when bleed off
  readonly crop: CropRect               // resolved (full image when edits.crop is null)
  readonly rotation: Rotation           // edits.rotation + (turned ? 90 : 0), mod 360
  readonly flipH: boolean
  readonly flipV: boolean
  readonly lowDpi: boolean
}
export interface Segment { readonly x1: Mm; readonly y1: Mm; readonly x2: Mm; readonly y2: Mm }
export interface PageModel {
  readonly index: number
  readonly size: SizeMm                 // oriented
  readonly safeArea: RectMm
  readonly tiles: readonly DrawTile[]

export function buildPageModels(layout: LayoutResult, setup: PageSetup, images: readonly ImageDescriptor[]): PageModel[]
```

- `PagePreview` component: renders one `PageModel` to a canvas at device pixel ratio, from `LoadedImage.bitmap`. Bleed is drawn as edge extension. Guides (safe area, trim, bleed) can be toggled. Clicking a tile calls `onSelect(imageId)` (D6).
- PDF:
  - `composePdf(pages, encoded: ReadonlyMap<ImageId, EncodedTileImage>)` is **pure and node-testable**, using `@pdfme/pdf-lib`. It embeds pre-encoded images, draws crop marks as vectors, and sizes each page exactly (mm → pt).
  - `exportPdf(pages, getBitmap, { onProgress, signal })` runs in a worker. It resamples each tile to 300 DPI for its printed size (never upscaling past the source), applies crop/rotation/flip, extends the edges for bleed, encodes JPEG (quality 0.92), and processes one page at a time. It returns a `Blob`.
- `ExportDialog` component: progress, cancel, download with the D10 file name.

## Global constraints for every M1 sub-plan

- Follow `CLAUDE.md`:
  - branch per PR, Conventional Commit PR titles, squash, auto-merge after review
  - parallel worktrees under `.worktrees/`
  - `E2E_PORT=<unique>` when running E2E in parallel
- TypeScript strict and `noUncheckedIndexedAccess`. No `any`. No non-null assertions without a comment.
- Pure core (`model`, `layout`, `render/page-model`, `render/pdf/compose`) has **no DOM access**, so it can be unit-tested in `node`.
- **Privacy:** photos are never persisted and never sent anywhere. The only fetch of user-related data is the URL the user typed. Add an E2E test that fails if any request other than same-origin assets or the user-typed URL happens during import → layout → export.
- **i18n:** no literal UI strings in `.tsx`. Every string is in the owning namespace JSON.
- **Accessibility:** WCAG 2.2 AA, keyboard-complete, axe-clean in light and dark (E2E).
- **Performance budgets (spec §3):**
  - initial app JS < 250 KB gzipped (enforced in CI by E)
  - layout for 50 items < 500 ms
  - preview update < 200 ms for ≤ 20 images
- **TDD:** every pure module is test-first; components get behaviour tests (Testing Library) for interactions.
- **Versions:** sub-plans B–E use only the dependencies A installs.
