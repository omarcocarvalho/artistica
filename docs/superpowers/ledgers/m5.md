| Task | PR | Merge commit | Review |
|---|---|---|---|
| Centre-line dashes that fit small tiles (M5-R20) | #154 | the squash of #154 on `master` | Contract met: `centreDashMm(widthMm, tileShortMm)` matches M5-R20 and the overview signature; the dash is computed once in `tileLinesFor` from `min(trim.w, trim.h)` (page mm, so a turn does not change it), and neither renderer changed (preview = PDF). No golden snapshot changed. Privacy, determinism, i18n and accessibility unaffected (pure function, no UI, no strings, no storage, no requests). The PR's hand-checked table and its mutation table (M1 to M10, E1, E2) were re-checked. **One finding fixed:** at exactly `short = 30 × width` the branch compared `6w + 4w` with `30w / 3`, and for about 16 % of widths those differ by one ulp, so the scaled branch returned values one ulp off M3's (e.g. w = 0.33854…, gap 1.3541630759482552 for 1.3541630759482555), contrary to "M3's dash, byte for byte, when short ≥ 30w". The PR's test used three hand-picked widths and the `short >= 30w` property almost never samples the exact boundary. The comparison now allows a relative 1e-12 (`dash + gap <= period * (1 + 1e-12)`), the exact-boundary test is a property over all widths plus two of the failing widths, and a new case checks that a tile a hair under 30w (w = 2, short = 60 × (1 − 1e-9)) still scales, so a loose tolerance is caught. Reviewer mutations: short / 2.5 for short / 3 (6 tests fail); dash and gap swapped in the scaled branch (9); floor 2w for 2.5w (3); `tileLinesFor` passes `trim.w` (2); tolerance removed (exact-boundary property fails); tolerance 1e-3 (survived, killed by the new hair-under case); page model ignores the tile (`Infinity`), E2E small-tile L-X1 fails (PDF 34.0 pt, expected 8.5 pt). Checks: lint, format:check, typecheck, test:coverage (2562 tests, 98.68 % statements, 90.08 % branches), test:perf, build; `e2e/lines.spec.ts` on chromium and webkit green (a first parallel webkit run lost its browser to SIGKILL under local load in the unchanged 3-tile L-X1; 15 of 15 serially). |
