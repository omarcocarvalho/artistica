## D4

PR #153 (`test(e2e): merge the two worker probes`), merge commit: recorded in the merge's own commit message and the M5 final review. One `installWorkerProbe` in `e2e/support/workers.ts` (Proxy on the constructor, `postMessage`/`terminate` patched on the prototype) writes one `__workerLog` of `new`/`post`/`prepare`/`terminate` with timestamps and the script name; `workerPosts`, `maxLiveWorkers`, `workerLog` and `summarizeLandmarkWorkers` keep their names and results. G-X2, G-D3, G-D8 and M3 use it; the self-check runs on every project.

- Review: semantics checked against both old probes. Posts from unknown workers still count under `other`; a second `terminate` of one worker still counts once; `post` events never reach `modelsPerWorker`; `post` is logged before the native call, as the old counter did. No privacy surface (test-only code; nothing leaves the page). Determinism unaffected.
- Finding, fixed: no test showed the probe could see two workers alive at once, so a probe that capped the peak at 1 passed the self-check and G-X2 (which asserts `≤ 1`). Added a self-check on every project: two test workers start, the first is terminated twice, two more start while the second lives; it asserts the log order and `maxLiveWorkers` = 3.
- Mutations run by the reviewer (chromium): `post` not logged → G-D3 and the self-check fail; peak clamped to 1 → survived the PR's tests, killed by the new test; peak kept as a counter (a second `terminate` counts again) → killed by the new test (2 instead of 3).
- Runs: lint, format:check, typecheck, test:coverage, test:perf, build green; `guides.spec.ts`, `mobile-flow.spec.ts` (without `@slow`) and `support-selfcheck.spec.ts` on all five projects: 77 passed, 131 skipped by project gating; 7 mobile-webkit tests that do not install the probe flaked (browser closed, local load average above 20) and passed on retry.
- Ruling (port): the implementer ran on 4707 instead of 6804; accepted, the port does not affect results.
- Ruling (`workerLog` shape): `workerLog` now also returns `post` events and every event carries `name`; accepted, the plan asks for one log of every `postMessage`, and `summarizeLandmarkWorkers` ignores `post` events, so M3's figures are unchanged.
- Ruling (self-check layout): the chromium-only self-checks move into a `describe` that calls `runOnly('chromium')` so the probe tests can run on every project; accepted, `runOnly` is a `beforeEach` and scopes to its `describe`.
