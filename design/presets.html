Named presets

A preset keeps the page setup, the study settings and the line settings under a name, on this device. It never holds a photo or anything made from one, and it never turns on edge, face or pose guides. Strings here are the ones the app uses.

In the top bar, before Export, on desktop and on the phone. It opens the Presets dialog (a bottom sheet on the phone).

Desktop: label and icon. Phone: the same button at 44 px.

Export all

One JSON file with every preset, downloaded at once (nothing is uploaded). It holds settings only: never a photo, a file name or anything made from a photo.

Import: it worked

“Import…” opens a file chooser for .json files (separate from the photo dropzone). The result shows under the list.
