How the phone flow works

  • Five steps, one task each. The step bar is also tappable, so you can jump back.
  • Settings and the live preview are the same engine as desktop; Preview is a swipeable page carousel.
  • Per-image edit opens as a bottom sheet (tap any thumbnail in step 1).
  • Lines sit inside the Studies step (collapsed) to keep the five steps from the spec.
  • All targets ≥ 44 px; inputs use 16 px text so iOS doesn't zoom.
  • Export runs page by page with progress, to keep phone memory low.
